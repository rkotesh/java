3. Problem
=> Minimum platforms

given arrival & departure timing of train, find the minimum requirement so that no train has to wait given:

Arrival : 900 940 1100 1500 1800
Departure : 910 1200 1120 1130 1900 2000
Algorithm Minimum Platforms(arrival, departure)


input:
arrival[] -> arrival times of trains
departure[] -> departure times of trains

Output:
Minimum number of platforms required

Algorithm:
step-1:
Sort Arrival[] in ascending order

Step-2:
Sort.departure[] in ascending order

Step-3:
j <- 0
j <- 0

platforms <- 0
maxPlatforms <- 0

Step-4:
while i<number of trains
and j < number of trains

if arrival[i] <= departure[i]

platforms <- platforms + 1

maxPlatforms <- max(maxPlatforms, platforms)

i <- j <- 1

else
platforms <- platforms - 1

j <- j <- 1

Step-5:
Return maxPlatforms

end Algorithm
