Dependency Injection :-
is design pattern in which an obj receives the other object. it depends on from an external source rather than creating itself.

Types =>
1. constructor - dependencies are provided through a class constructor.
2. Setter Injection - dependencies are provided through setter methods. 
3. Field Injections - (spring) dependencies are injected directly into the fields using an annotation such as auto wind.

ORM -> object relational mapping is a technique used to convert a class into a database.

Java Class -> Database Table 
Java Field -> Database Column

Class:

@Entity
public class Student {
@id
private Long id;
private String name;
private String email;
}


JPA-> is a specification that defines how java application should interact with the relational database.	
Hibernate -> is a implementation of JPA 
	
Important Annotations
1. @Entity
2. @Table
3. @Generated Value


@Entity 
marks a java class as a database entity
@Entity
public class Student {
}

------------------------------------------------------

@Table
specifies the database table
@Entity
@Table(name="students")
public class Student{
}

------------------------------------------------------

@Id
defines the primary key
@Id
private Long id;

------------------------------------------------------

@GenaratedValur
Automatically generates the primary key value
@GeneratedValue(strategy = GenerationType.IDENTITY)
private long id;

------------------------------------------------------

@Column
maps a java field to a database column
@Column(name = "Student_name")
private Sting name;

2 - Spring Security Verifies User

7 - Access API
